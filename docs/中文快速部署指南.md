# 中文快速部署指南

这份文档给第一次接手项目的同事使用。目标是从 GitHub 拉取代码，在自己的 Windows 或 Mac 电脑上完成配置，并跑通公众号内容平台。

## 1. 项目用途

`gzh-platform` 是一个公众号内容运营平台，包含：

- 热点抓取和选题库。
- AI 自动素材候选和正式素材库。
- 用户知识库上传。
- 文章工坊智能推荐素材并生成文章。
- 发布前改写和公众号草稿发布。
- 数据看板和公众号数据同步。
- 设置页配置向导和部署诊断。

## 2. 环境要求

建议：

- Git
- Python 3.10+
- Node.js 20+
- npm

检查命令：

```powershell
git --version
python --version
node --version
npm --version
```

Mac 可以使用：

```bash
git --version
python3 --version
node --version
npm --version
```

## 3. 拉取代码

```powershell
cd C:\Users\你的用户名\Documents
git clone https://github.com/AnziBai/gzh-platform.git
cd gzh-platform
```

## 4. Windows 一键启动

```powershell
.\start-dev.ps1
```

脚本会自动：

- 创建 `backend\.venv`。
- 安装后端依赖。
- 安装前端依赖。
- 启动后端和前端窗口。

启动后打开：

```text
http://127.0.0.1:3001/settings
```

如果已经装好依赖，只想启动服务：

```powershell
.\start-dev.ps1 -SkipInstall
```

## 5. Mac / Linux 手动启动

后端：

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

前端另开终端：

```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 3001
```

## 6. 首次打开后的配置顺序

打开：

```text
http://127.0.0.1:3001/settings
```

推荐按这个顺序：

1. 点击“配置向导”。
2. 设置本地工作区根目录。
3. 一键创建文章目录、素材目录、数据库目录。
4. 选择 AI 模型预设。
5. 填写或确认 AI API Key。
6. 填写微信公众号 AppID/AppSecret。
7. 在公众号后台配置本机公网 IP 白名单。
8. 测试 AI 连接。
9. 测试微信公众号连接。
10. 检查“开箱即用进度”是否满足你的使用目标。

密钥输入框留空保存时，会保留已有密钥，不会清空。

## 7. 必填配置

### 本地目录

如果没有单独的内容仓库，可以先创建：

```powershell
mkdir C:\gzh-content
mkdir C:\gzh-content\articles\published
mkdir C:\gzh-content\benchmarks
mkdir C:\gzh-content\assets
```

向导会写入类似配置：

```env
GZHPUBLISHER_ROOT=C:/gzh-content
ARTICLES_DIR=C:/gzh-content/articles/published
BENCHMARKS_DIR=C:/gzh-content/benchmarks
ASSETS_DIR=C:/gzh-content/assets
```

### AI 写作模型

推荐使用 OpenAI-compatible API，便于团队迁移到不同电脑。

```env
AI_PROVIDER=openai_compatible
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=你的 API Key
AI_MODEL=deepseek-chat
```

设置页支持预设：

- DeepSeek
- 通义百炼
- 智谱 GLM
- Kimi / Moonshot
- 火山方舟 / 豆包
- MiMo / TokenPlan
- 自定义 OpenAI-compatible

部分模型的额外参数可以写入：

```env
AI_EXTRA_BODY_JSON={"enable_thinking":false}
```

### 微信公众号

在微信公众号后台获取：

```env
WECHAT_APP_ID=你的 AppID
WECHAT_APP_SECRET=你的 AppSecret
```

必须把本机公网 IP 加入微信公众号后台 IP 白名单，否则无法同步数据或发布草稿。

## 8. 跑通完整业务流

### 抓热点

```text
选题库 -> 选择来源和时间窗 -> 全部平台抓取
```

成功后会看到热点列表，并在素材库出现 AI 自动收集候选。

### 审核素材

```text
素材库 -> AI 自动收集候选 -> 入库 / 改类入库 / 忽略
```

事实资料和爆款参考会进入正式素材库。

### 上传知识库

```text
素材库 -> Knowledge Base -> Upload .md/.txt/.pdf
```

Markdown/TXT 可直接用。PDF 需要安装 `pypdf`。

### 生成文章

```text
文章工坊 -> 输入主题 -> 智能推荐素材 -> 生成文章
```

系统会自动推荐知识库片段、事实素材和爆款参考。

### 发布前改写

```text
发布中心 -> 发布前改写
```

系统会生成新草稿，不覆盖原文。

### 发布到公众号草稿箱

确认文章后点击“发布”。这一步会真实写入微信公众号草稿箱。

## 9. 数据看板同步

手动同步：

```text
数据看板 -> 更新数据
```

命令行同步：

```powershell
cd backend
python scripts\sync_wechat_stats.py --source api
```

同步状态可在数据看板查看，也可调用：

```powershell
Invoke-RestMethod http://127.0.0.1:5001/api/analytics/sync-status
```

## 10. 常见问题

### 页面请求失败或 502

通常是后端没有启动。

```powershell
cd backend
python app.py
```

### AI 连接失败

检查：

- `AI_PROVIDER` 是否正确。
- `AI_BASE_URL` 是否是供应商兼容 endpoint。
- `AI_API_KEY` 是否有效。
- `AI_MODEL` 是否存在且账号有权限。
- `AI_EXTRA_BODY_JSON` 是否是合法 JSON object。

### 微信连接失败

常见原因：

- AppID 或 AppSecret 填错。
- 本机公网 IP 没有加入白名单。
- 当前公众号没有相关 API 权限。
- 公司网络或代理阻断 `api.weixin.qq.com`。

### PDF 上传失败

安装依赖：

```powershell
cd backend
.\.venv\Scripts\activate
pip install pypdf
```

Markdown/TXT 上传不受影响。

## 11. 更新代码

```powershell
git pull origin master
```

如果依赖有变化，重新运行：

```powershell
.\start-dev.ps1
```

## 12. 不要提交的本地文件

这些文件只属于自己的电脑，不要提交到 GitHub：

- `backend\.env`
- `backend\data\gzh_platform.db`
- `backend\scripts\wechat_stats_sync.log`
- 浏览器登录态、截图、临时抓取 HTML

项目 `.gitignore` 已默认忽略主要运行产物。
