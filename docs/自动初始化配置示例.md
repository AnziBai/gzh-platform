# 自动初始化配置示例

本文说明新环境如何自动配置目录和依赖，以及用户需要手动补齐哪些外部信息。

## 一键启动脚本

Windows 用户推荐运行：

```powershell
.\start-dev.ps1
```

脚本会做这些事：

1. 检查 Python 3.10+。
2. 创建 `backend\.venv`。
3. 安装 `backend\requirements.txt`。
4. 检查 Node.js 和 npm。
5. 安装前端依赖。
6. 启动后端 `http://127.0.0.1:5001`。
7. 启动前端 `http://127.0.0.1:3001`。

只启动不安装：

```powershell
.\start-dev.ps1 -SkipInstall
```

## 设置页配置向导

首次打开：

```text
http://127.0.0.1:3001/settings
```

点击“配置向导”。向导负责降低用户配置成本：

- 创建文章目录。
- 创建素材目录。
- 创建数据库目录。
- 写入 `backend/.env` 的目录配置。
- 根据模型预设填充 AI Base URL 和推荐模型。
- 自动探测本地环境变量或 `.env` 中已有 API Key。
- 保留已有密钥，空输入不会覆盖密钥。

向导不会在网页里执行 `pip install` 或 `npm install`。依赖缺失继续由启动脚本、诊断和本文档提示处理。

## 推荐目录结构

用户可以选择任意本地目录。一个简单结构：

```text
C:/gzh-content/
  articles/
    published/
  benchmarks/
  assets/
  database/
  knowledge/
```

对应 `.env`：

```env
GZHPUBLISHER_ROOT=C:/gzh-content
ARTICLES_DIR=C:/gzh-content/articles/published
BENCHMARKS_DIR=C:/gzh-content/benchmarks
ASSETS_DIR=C:/gzh-content/assets
```

数据库默认仍在 `backend/data/gzh_platform.db`。向导会确保数据库目录存在。

## 完整 `.env` 示例

```env
GZHPUBLISHER_ROOT=C:/gzh-content
ARTICLES_DIR=C:/gzh-content/articles/published
BENCHMARKS_DIR=C:/gzh-content/benchmarks
ASSETS_DIR=C:/gzh-content/assets

WECHAT_APP_ID=
WECHAT_APP_SECRET=
WECHAT_STATS_DAYS_BACK=365
WECHAT_STATS_MAX_WORKERS=1

```

## 国内模型预设

设置页会从 `GET /api/settings/model-presets` 读取预设。当前支持：

| 预设 | 说明 |
| --- | --- |
| DeepSeek | 通用写作、摘要、分类 |
| 通义百炼 | 阿里云 Model Studio OpenAI-compatible |
| 智谱 GLM | GLM-4 系列和 embedding 场景 |
| Kimi / Moonshot | 长文本阅读和写作 |
| 火山方舟 / 豆包 | 字节系 OpenAI-compatible 接口 |
| MiMo / TokenPlan | 小米 MiMo/TokenPlan 兼容接口 |
| 自定义 | 任意 OpenAI-compatible 服务 |

如模型需要额外参数，可写：

```env
AI_EXTRA_BODY_JSON={"enable_thinking":false}
```

该字段必须是 JSON object。

## 搜索与热点配置

如果团队有外部搜索服务，可配置：

```env
SEARCH_PROVIDER=custom
SEARCH_BASE_URL=https://example.com/search
SEARCH_API_KEY=...
```

搜索结果必须带来源 URL。没有来源 URL 的事实材料不应确认入库。

`HOT_SOURCE_PRESETS_JSON` 可用于扩展热点源预设。保持 JSON 格式，避免在 `.env` 中写入未转义换行。

## 知识库依赖

支持上传：

- Markdown：`.md`
- 文本：`.txt`
- PDF：`.pdf`

PDF 需要：

```powershell
cd backend
.\.venv\Scripts\activate
pip install pypdf
```

诊断页会把 PDF parser 缺失显示为非阻塞项。Markdown/TXT 上传仍然可用。

## 向导完成后的检查

设置页应显示：

- 生成文章可用。
- 同步公众号数据可用。
- 发布草稿可用。
- 归档记录可用。

如果某项未完成，按诊断提示处理。

## 不覆盖密钥原则

设置页保存配置时：

- Secret 输入框留空表示保留现有值。
- 只有用户输入新值时才覆盖密钥。
- README 和 docs 不应记录真实密钥。

## 跨电脑迁移建议

1. 在新电脑拉取 GitHub 代码。
2. 运行 `.\start-dev.ps1`。
3. 打开设置页配置向导。
4. 重新选择本地内容目录。
5. 填写该电脑可用的 AI Key 和公众号凭证。
6. 配置公众号后台 IP 白名单。
7. 点击 AI 和微信连接测试。

不要直接复制旧电脑的 `backend/.env` 到公共仓库。
