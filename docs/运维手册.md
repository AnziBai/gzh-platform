# gzh-platform 运维手册

本文记录本地启动、配置检查、数据同步、发布前检查和常见故障处理。

## 本地启动

Windows 推荐：

```powershell
.\start-dev.ps1
```

默认地址：

```text
Backend:  http://127.0.0.1:5001
Frontend: http://127.0.0.1:3001
```

如果依赖已经安装好，只想启动服务：

```powershell
.\start-dev.ps1 -SkipInstall
```

手动启动后端：

```powershell
cd backend
.\.venv\Scripts\activate
python app.py
```

手动启动前端：

```powershell
cd frontend
npm run dev -- --host 127.0.0.1 --port 3001
```

## 首次部署检查

打开：

```text
http://127.0.0.1:3001/settings
```

优先使用“配置向导”。它会：

- 创建文章目录、素材目录、数据库目录。
- 写入 `backend/.env` 的本地目录配置。
- 根据模型预设填充 AI Provider、Base URL、Model。
- 自动探测本地已有 API Key 并填充。
- 保留已存在密钥，不会因为输入框留空而清空。

诊断项应重点检查：

- `.env` 是否存在。
- `ARTICLES_DIR`、`BENCHMARKS_DIR` 是否存在。
- AI Base URL、API Key、Model 是否可用。
- 微信公众号 AppID/AppSecret 是否填写。
- 本机公网 IP 是否在公众号后台白名单。
- Node.js、Wenyan 依赖、Git 是否可用。
- PDF parser 是否安装。该项只影响 PDF 知识库上传，不影响 Markdown/TXT。

## 环境变量速查

| 变量 | 运维说明 |
| --- | --- |
| `GZHPUBLISHER_ROOT` | 本机内容根目录 |
| `ARTICLES_DIR` | 文章生成和发布读取目录 |
| `BENCHMARKS_DIR` | 正式素材 Markdown 文件目录 |
| `ASSETS_DIR` | 素材资源目录 |
| `WECHAT_APP_ID` / `WECHAT_APP_SECRET` | 公众号凭证，需配合 IP 白名单 |
| `AI_PROVIDER` | `claude_cli` 或 `openai_compatible` |
| `AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL` | 国内模型或 OpenAI-compatible 配置 |
| `AI_PRESET_PROVIDER` | 设置页当前模型预设 |
| `AI_EXTRA_BODY_JSON` | 模型额外参数，必须是 JSON object |
| `SEARCH_PROVIDER` / `SEARCH_API_KEY` / `SEARCH_BASE_URL` | 外部搜索 API 配置 |
| `HOT_SOURCE_PRESETS_JSON` | 热点源预设 JSON |
| `HTTPS_PROXY` | 可选代理 |
| `FLASK_PORT` | 默认 5001 |

## 手动触发关键流程

### 热点抓取

前端路径：

```text
选题库 -> 选择来源/时间窗/关键词 -> 全部平台抓取
```

成功标志：

- 任务日志出现抓取数量、过滤数量、入库数量。
- 选题表格出现热点。
- 素材库出现“AI 自动收集候选”。

### 素材候选审核

前端路径：

```text
素材库 -> AI 自动收集候选 -> 入库/改类入库/忽略
```

成功标志：

- 总素材数增加。
- 候选从待确认列表消失。
- `BENCHMARKS_DIR` 中出现对应 Markdown 文件。

### 知识库上传

前端路径：

```text
素材库 -> Knowledge Base -> Upload .md/.txt/.pdf
```

限制：

- 单文件最大 10MB。
- Markdown/TXT 直接可用。
- PDF 需要 `pypdf`。

### 文章生成

前端路径：

```text
文章工坊 -> 输入主题 -> 智能推荐素材 -> 生成文章
```

成功标志：

- 推荐出知识片段、事实素材或爆款参考。
- 任务日志显示生成完成。
- 文章列表出现新文章。

### 发布前改写

前端路径：

```text
发布中心 -> 发布前改写
```

成功标志：

- 弹窗显示“新草稿”。
- 待发布列表数量增加。
- 原文未被覆盖。

### 发布到公众号草稿箱

最终“发布”会真实调用微信公众号接口写入草稿箱。执行前应人工确认文章内容、公众号配置和 IP 白名单。

## 数据看板同步

前端手动同步：

```text
数据看板 -> 更新数据
```

命令行同步：

```powershell
cd backend
python scripts\sync_wechat_stats.py --source api
```

HTML dry-run：

```powershell
cd backend
python scripts\sync_wechat_stats.py --source html --html-path scripts\publish_records.html --dry-run
```

JSON dry-run：

```powershell
cd backend
python scripts\sync_wechat_stats.py --source json --json-path scraped_articles.json --dry-run
```

先检查 `matched`、`unmatched`、`ambiguous`。确认没有明显错配后再去掉 `--dry-run`。

Windows 定时任务可执行：

```text
backend\scripts\run_wechat_stats_sync.bat
```

建议频率：

- 普通使用：每天 09:00 和 18:00。
- 发文频繁：每 2-4 小时。

## 常见故障

### 前端 502 或请求失败

后端没有启动或端口不可达。

```powershell
cd backend
python app.py
```

如果后端代码刚改过但页面仍显示旧错误，重启 Flask 进程。

### AI 连接失败

检查：

1. `AI_PROVIDER` 是否正确。
2. `AI_BASE_URL` 是否是供应商 OpenAI-compatible endpoint。
3. `AI_API_KEY` 是否有效。
4. `AI_MODEL` 是否存在且账号有权限。
5. `AI_EXTRA_BODY_JSON` 是否是合法 JSON object。

### AI 生成或改写提示缺少 frontmatter

2026-05-12 后正文生成和发布前改写都已做规范化兜底。若仍出现该错误：

1. 确认后端进程已经重启到最新代码。
2. 检查模型是否返回空内容。
3. 检查 `backend/prompts/writer_default.md` 是否被破坏。

### 微信 API 返回 IP 白名单错误

在微信公众号后台添加当前机器公网 IP。保存后重新点击设置页“测试微信公众号连接”。

### 发布失败但文章审查通过

按顺序检查：

1. Node.js 是否在 PATH。
2. `backend/publish_wenyan.mjs` 是否存在。
3. 全局 `@wenyan-md/mcp` 是否安装。
4. AppID/AppSecret 是否正确。
5. 公众号草稿箱 API 权限是否可用。

### 数据看板全是 0

按顺序检查：

1. 微信连接测试是否通过。
2. 是否执行过“更新数据”。
3. `GET /api/analytics/sync-status` 是否显示失败。
4. 同步结果是否有大量 `unmatched` 或 `ambiguous`。
5. 当前公众号是否确实发布过这些文章。

### PDF 知识库上传失败

安装 PDF 解析依赖：

```powershell
cd backend
.\.venv\Scripts\activate
pip install pypdf
```

Markdown/TXT 知识库上传不依赖该组件。
