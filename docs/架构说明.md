# gzh-platform 架构说明

本文面向接手开发和维护的同事，说明系统主要模块、数据流和数据模型。

## 总体结构

```text
frontend/ React + Vite + Ant Design
  -> /api/*
backend/ Flask + SQLAlchemy + SQLite
  -> 微信公众号 API
  -> AI Provider 或 Claude CLI
  -> Wenyan 排版发布脚本
```

## 后端模块

| 模块 | 责任 |
| --- | --- |
| `backend/app.py` | Flask 应用入口，注册所有 `/api` 蓝图 |
| `backend/config.py` | 从 `backend/.env` 读取本地配置 |
| `backend/database.py` | 初始化 SQLite，创建/补齐表结构 |
| `backend/models.py` | SQLAlchemy 数据模型 |
| `backend/routes/analytics.py` | 数据看板、文章统计、微信数据同步状态 |
| `backend/routes/settings.py` | 本机配置读取/保存、连接测试、部署诊断 |
| `backend/services/wechat_service.py` | 微信公众号 token、发布列表、datacube 数据拉取 |
| `backend/services/wechat_stats_sync.py` | 统一统计字段归一化、标题匹配、写入 `article_stats` |
| `backend/services/sync_status_service.py` | 记录和读取最近一次数据同步状态 |
| `backend/scripts/sync_wechat_stats.py` | 命令行同步入口，支持 API/HTML/JSON 来源 |

## 数据看板同步流程

```text
用户点击“更新数据”或定时任务执行脚本
  -> 拉取微信公众号发布记录
  -> 拉取 datacube 统计数据
  -> normalize_api_stats()
  -> sync_article_stats()
       -> 精确匹配标题
       -> 唯一高置信 partial 匹配
       -> 歧义标题进入 ambiguous，不写库
       -> 未匹配标题进入 unmatched
  -> 写入 article_stats
  -> 写入 sync_status
  -> 前端每 60 秒刷新最近同步状态
```

## 数据模型

| 表 | 用途 |
| --- | --- |
| `articles` | 本地文章元数据、发布状态、发布结果 |
| `article_stats` | 每篇文章的阅读、分享、点赞、推荐、评论、划线等统计 |
| `benchmarks` | 爆款素材库 |
| `topics` | 选题库 |
| `tasks` | 后台任务状态 |
| `sync_status` | 最近一次数据看板同步状态 |

`sync_status` 目前使用固定 `id=1` 保存最近一次同步结果，包括：

- `status`: `never` / `success` / `failed`
- `message`: 给前端展示的人类可读摘要
- `result_json`: 最近一次同步的结构化结果
- `started_at` / `finished_at` / `updated_at`

## 数据可信度原则

- 微信 API 是阅读、分享、点赞等统计的权威来源。
- `ori_page_read_count` 不是评论数，不能映射为留言/评论。
- 歧义标题不写入数据库，避免把 A 文章数据覆盖到 B 文章。
- HTML/JSON/API 导入都应走 `wechat_stats_sync.py` 的统一归一化和匹配逻辑。
- 导入外部抓取数据时先使用 `--dry-run`，检查 `matched/unmatched/ambiguous`。

## 关键 API

| API | 用途 |
| --- | --- |
| `GET /api/analytics/overview` | 数据看板概览 |
| `GET /api/analytics/articles` | 文章统计列表，按阅读量降序 |
| `POST /api/analytics/fetch-stats` | 手动触发微信公众号数据同步 |
| `GET /api/analytics/sync-status` | 读取最近一次同步状态 |
| `GET /api/settings/diagnostics` | 部署环境检查 |
| `POST /api/settings/test-wechat` | 测试微信公众号凭证/IP 白名单 |
| `POST /api/settings/test-ai` | 测试 AI 模型连接 |
